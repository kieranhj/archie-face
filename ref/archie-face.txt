=> What would be a sensible palette arrangement?
    Assume 64 hues? (6 bits)
    Max 16 saturations (4 bits) => Use 2 bits for 12-bit palette? V:4 | S:2 | H:6 (then greys are V<<8)
    Max 16 values (4 bits)
    Total 14 bits = 16384 entries... very wasteful, e.g. s=0 => all hues are same for a give value (greys) ==> uses 228 colours
    Could just as easily create 12-bit RGB palette with 4096 entries containing the nearest match. ==> uses all 256 colours
